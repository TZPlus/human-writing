# 活人感写作

这是 `human-writing` 的 WorkBuddy 专家包。它加载完整版写作 Skill，从材料和事实边界出发完成中文创作与改稿，让文章有具体信息、清楚判断和自然节奏。

## 适合做什么

- 根据材料写公众号文章、知乎回答、博客、评论、人物稿、行业稿、教程、评测、口播或演讲稿
- 把已有中文草稿改得更自然，同时保留原意、事实、数字和作者立场
- 分别处理现实、虚构与混合创作，不拿假细节填充现实内容
- 在交稿前检查重复解释、报告腔、营销腔与常见模型腔

## 可以这样问

```text
使用活人感写作，把我的材料写成一篇有事实支撑、读起来像具体的人在说话的作品。
```

```text
把这篇 AI 味很重的中文稿改得自然一些，保留事实和我的判断。
```

```text
根据这些真实材料，写一篇有判断、有细节的公众号文章。
```

## 工作边界

现实稿不会补写用户没有提供的亲历、数字、引语或现场。材料不足时，专家会先研究、最多追问三个关键问题，或者把题目和篇幅收紧。公开材料写成的事实稿会保留少量关键来源；个人经历与观点稿默认不附来源。
